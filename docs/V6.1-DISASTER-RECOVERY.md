# V6.1 FIXED — Disaster Recovery & Cloud Independence

## Goal
Cloudflare is the primary runtime, but HAMZEHI SOCIAL AI must not be architecturally locked to it.

## Added
- Recovery manifest endpoint
- Database recovery snapshot records
- Provider configuration records for primary/backup providers
- Migration run records
- Explicit portability rules
- No website integration
- No R2
- No GitHub dependency
- Approval gate remains mandatory

## Recovery principle
The application contract is provider-neutral:
1. Business data lives in D1 today, but is modeled for export.
2. Secrets are externalized and are never stored in the dashboard.
3. Provider-specific code is isolated at the infrastructure boundary.
4. A backup provider can be introduced without changing the website.

## Important
V6.1 FIXED creates the portability and recovery layer. It does NOT pretend that a second live backend exists yet. A live failover provider must be deployed and tested separately.
